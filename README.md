### scipick — an LLM leaderboard for research work

[**lyj090.github.io/scipick**](https://lyj090.github.io/scipick/) · [source](https://github.com/lyj090/scipick)

General leaderboards optimise for chat quality, which is the wrong objective when
picking a model to write code, read a repository, or work through a long document.
scipick treats *strongest*, *best value* and *best for code* as three views over one
metric set, so the numbers stay comparable; the weights live in a config file, so a
new view needs no code.

The ranking rules are deliberately conservative where a score can mislead: models
with too little data are not ranked above models with plenty; "price not published"
does not mean free; and the highest points-per-dollar is often not the model to use.
The rules and their trade-offs are stated on the page rather than left implicit in
the source.

**scipick** — [在线榜单](https://lyj090.github.io/scipick/) · [源码](https://github.com/lyj090/scipick)

通用榜单优化的是闲聊质量，而写代码、读仓库、读长文档时这并不是合适的目标。
scipick 把「最强」「最值」「最适合写代码」当作同一组指标下的三种视角，数字因此保持可比；
权重写在配置文件中，新增一种视角不需要改代码。

评分规则在容易误导的地方保持保守：数据不足的模型不会被排在数据充足的模型之前；
「没有公布价格」不等于免费；每美元得分最高的模型往往也不是该用的那一个。
这些规则及其取舍写在榜单页面上，而不是留在源码里。
